# Dad Joke Showdown — u-mfnakmal-dad-joke-showdown-1d2ce3e5

A pencil sharpener that talks back — and insists it was only trying to make a point.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes a single dad joke (under 200 characters) to `entry.txt` inside `MAKEFUN_OUTPUT_DIR`.
